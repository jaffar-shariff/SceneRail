# Core Visual Style Principles

These six production systems are compact starting points. For the full named style catalog with thirty-plus original directions, examples, and detailed recipes, see the [Masteraiskill Style Atlas](../styles/STYLEBOOK.md).

Presets are starting points, not immutable templates. Select by narrative job, audience, available assets and channel identity, then capture the final choices in the project style bible. Do not use a single visual language for every topic by habit.

## 1. Paper-card editorial 2D

**Best for:** business, economics, company stories, history, systems and explainers that benefit from tangible metaphor.

**Look:** flat 2D cut-paper cards, paper fibers/grain, slightly imperfect hand-cut edges, layered paper shadows, simple cutout objects, editorial typography, collage-like composition and clear negative space.

**Motion:** slide, reveal, fold-like transitions, paper-layer parallax, controlled scale/position moves, small impacts only when they support an idea. Use 2D depth cues rather than converting every object into faux 3D.

**Do:** keep materials coherent; use original paper shapes; make key numbers and causal mechanisms immediately legible; vary composition while preserving a stable palette; allow important claims to hold on screen.

**Avoid:** random floating paper, exaggerated bevels, plastic CGI, unnecessary rotations, cluttered asset piles, faux-photographic textures, decorative motion competing with narration, generated-text artifacts.

## 2. Editorial data journalism

**Best for:** numbers, financial mechanisms, public datasets, trends, comparisons and evidence-heavy claims.

**Look:** strong type hierarchy, precise axes and baselines, source footnotes, limited color semantics, clean grids and meaningful chart labels.

**Motion:** progressive data reveal, draw-on lines, restrained counts, active-versus-context highlights and controlled transitions. Never animate a value in a way that changes its meaning.

**Avoid:** 3D bars that distort comparisons, cropped axes without disclosure, unexplained units, unsupported precision, random chart colors and number reveals without a source.

## 3. Whiteboard / sketch reasoning

**Best for:** a step-by-step process, a chain of causes, formulas, architecture or an intentionally hand-drawn lesson.

**Look:** original line drawings, handwritten accents, sparse palette and ample white space.

**Motion:** SVG stroke draw-on, ordered reveals, a marker/hand aligned to the actual path when used, and holds long enough to follow the reasoning.

**Avoid:** a fake hand drawing unrelated paths, illegible handwriting, too many strokes at once, slow decorative drawing that delays the explanation.

## 4. Isometric / exploded system

**Best for:** infrastructure, product internals, a layered business system, factory, supply chain or object breakdown.

**Look:** consistent isometric axes, deliberate depth, controlled face shading and a clear separation between layers.

**Motion:** build from lower layers to upper layers; pull components apart along coherent axes; use camera drift only when it aids orientation.

**Avoid:** mixing incompatible projection conventions, perspective shrink when an isometric view is intended, confusing exploded layouts and gratuitous spins.

## 5. Cinematic code-drawn abstraction

**Best for:** intangible concepts, networks, scale, abstract physics, transitions, or topics where original procedural visuals can communicate more cleanly than stock footage.

**Look:** procedural shapes, controlled lighting/materials, limited particle systems and strong subject framing.

**Motion:** seed randomness, derive all state from frame/time, avoid unbounded particle effects, and retain a readable focal point.

**Avoid:** generic AI-looking particles, random animation without narrative purpose, performance-heavy scenes that add little meaning.

## 6. Documentary / mixed-media editorial

**Best for:** real events, archival history, founder/company timelines, geographic stories and claims where real-world evidence matters.

**Look:** licensed/source-verified images, footage, documents, maps and original graphics unified through a style bible.

**Motion:** restrained pans, animated annotations, timeline reveals and transitions based on editorial logic.

**Avoid:** treating search results as reusable, inventing archival imagery, presenting illustrative AI visuals as real evidence, or reusing third-party audio without permission.

## Choosing a preset

1. State the explanatory job of each planned sequence.
2. Choose one primary system and at most one supporting system.
3. Write a style bible with color meaning, type hierarchy, texture, layout, motion, captions and audio.
4. Create three style frames: opening, information-dense scene and closing.
5. Check them at final output size before producing the whole film.
6. If the style is changed, update the style bible and re-render affected scenes consistently.

The preset is approved only after representative frames have been rendered and inspected. A text description is not proof of the actual visual result.
