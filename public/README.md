# Public Assets

Remotion serves files from this folder. Example optional narration path:

- Store approved narration at `public/audio/narration.mp3`.
- Set the Remotion composition prop `narrationFile` to `audio/narration.mp3`.

Do not add copyrighted samples, private recordings, API keys, or client/customer media to the public repository. Put real project-specific assets in the project working directory or a private/non-tracked location. Record origins and permissions in that project's asset ledger.
