# Examples

- `timeline.json` is an example of the canonical scene timeline and a fixture for `scripts/validate_timeline.py`.
- The Remotion composition `MasteraiskillDemo` in `src/Root.tsx` is an initial visual rendering example. It includes an opening, progressive diagram, illustrative data reveal, and closing card.
- Run `npm run render:sample` after installing dependencies to create an MP4. Run `scripts/probe_mp4.py` against the output to inspect measured metadata.

The chart values in the renderer demo are illustrative and must not be reused as factual data in a published video.
