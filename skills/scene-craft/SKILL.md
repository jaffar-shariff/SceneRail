# Scene Craft

Choose scene grammar according to what the viewer must understand. Do not select effects before identifying the explanatory purpose.

## Scene selection
- Relationships/process: diagram with entities revealed before connectors and labels.
- Quantitative comparison: chart with source-backed values, clear units, valid scale and baseline.
- Change over time: timeline with meaningful anchors and an explanatory camera path.
- Abstract mechanism: one familiar analogy, kept visually and verbally consistent.
- Object/system internals: labeled breakdown or exploded view with coherent spatial axes.
- Hand-drawn reasoning: SVG stroke reveal paced to narration.
- Editorial contrast/metaphor: original paper-card collage with controlled texture and layered composition.
- Repeated records or personalized stats: data-driven scene template.
- Real-world event: approved footage/imagery with recorded provenance and usage rights.

## Craft standards
- Each scene has one primary visual idea.
- Preserve palette, color semantics, type scale, grid and motion rules across the film.
- Reveal information progressively; don't overwhelm the viewer with every label at once.
- Animation must be frame-deterministic: visual state derives from frame/time and explicit inputs.
- Respect safe areas, contrast, reading time and output aspect ratio.
- Avoid generic icon filler, arbitrary zooms, decorative motion that competes with meaning, and unnecessary 3D.
- Validate chart values/units independently from drawing code.
- Test longest text and smallest label at final size.

## Iteration
1. Implement the simplest scene that explains the beat.
2. Render a start frame, active-motion frame and settled frame.
3. Inspect layout, legibility and style consistency.
4. Fix real defects and inspect nearby frames for regressions.
5. Reuse components only when they reduce genuine duplication.
